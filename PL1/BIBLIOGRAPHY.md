# PL/I Bibliography

## Primary references

### IBM Enterprise PL/I for z/OS Language Reference
- **Title:** Enterprise PL/I for z/OS Language Reference (SC27-8887)
- **URL (release 6.2, current, checked 2026-10-07):** https://www.ibm.com/docs/en/epfz/6.2.0
  (the 6.2 Language Reference is SC31-5716-00). Release 6.1 (SC27-8887):
  https://www.ibm.com/docs/en/eplienfp/6.1?topic=reference-enterprise-pli-zos-language
- **Notes:** Definitive reference for IBM Enterprise PL/I.

### IBM Enterprise PL/I for z/OS Programming Guide
- **Title:** Enterprise PL/I for z/OS Programming Guide (SC27-8888)
- **URL (release 6.2, current, checked 2026-10-07):** https://www.ibm.com/docs/en/epfz/6.2.0
  Release 6.1 (SC27-8888):
  https://www.ibm.com/docs/en/eplienfp/6.1?topic=guide-enterprise-pli-zos-programming
- **Notes:** Practical usage guidance.

### ANSI PL/I Standard
- **Title:** American National Standard for Information Systems —
  Programming Language PL/I (X3.74-1987)
- **Notes:** The formal standard, now largely superseded by IBM
  Enterprise PL/I in practice.
