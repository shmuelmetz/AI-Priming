# NetRexx Bibliography

## Primary references

### NetRexx Language Reference
- **Author:** Mike Cowlishaw
- **URL:** https://www.netrexx.org/ (release 4.02-GA Language Reference:
  https://www.netrexx.org/documents/NetRexx%204.02-GA%20Language%20Reference.pdf; checked 2026-10-07)
- **Notes:** Definitive specification. NetRexx is a superset of classic
  Rexx idioms adapted for the Java platform.

### NetRexx Quick Start Guide
- **URL (release 4.02-GA):** https://www.netrexx.org/documents/NetRexx%204.02-GA%20QuickStart%20Guide.pdf
  (current, checked 2026-10-07; the old https://www.netrexx.org/files/nrquick.pdf
  no longer resolves)
- **Notes:** Practical introduction.

### RexxLA NetRexx resources
- **URL:** https://www.rexxla.org/
- **Notes:** RexxLA maintains the open source NetRexx compiler.
